## 🧭 理念

> **简单、可靠、实用。**  
> 工具存在的意义，是让开发者忘记工具本身，专注于真正的业务逻辑。

我不追求炫技。我追求的是——当你再次面对 Excel、HTTP、SQL 这些"不得不做又不想花时间"的任务时，会想起"有个工具能搞定"，然后 5 分钟内收工。
