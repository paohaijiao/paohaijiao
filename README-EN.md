## 🧭 Philosophy

> **Simple, reliable, practical.**  
> The purpose of a tool is to let developers forget about the tool itself and focus on real business logic.

I don't chase flashy techniques. I chase the moment when you face those "have to do but don't want to spend time on" tasks like Excel, HTTP, SQL — and you remember "there's a tool that can handle it," then wrap up in 5 minutes.
